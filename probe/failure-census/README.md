      //pct:pct_duckdb //pct:pct_h2

The corpus passes carry `-Dlegend.probe.failures=true` in `spec/BUILD.bazel`, on this branch only.

What the columns count:
- `planned` counts distinct failures per test: the same (kind, where, message) planned twice in one test, by a
  measure or a second plan, counts once.
- `raised, caught by assertError (arm)` means the assertError arm raised it from its record (`AssertErrorRuns`).
- `never raised` means the plan recorded it but the run did not reach it.

PCT channel A (`pct_duckdb`, `pct_h2`): **0 lines**. Channel A runs the product's `Execution.run`, which builds no
test plan, so nothing there reaches `Failures`.
