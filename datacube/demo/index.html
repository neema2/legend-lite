200,000 rows in DuckDB-WASM, pivoted in the browser. Drag a column from the Columns panel into a zone to group or pivot by it, and right-click the grid for everything else — sorting, filters, pivots, exports, heatmaps and Properties… (also Ctrl+E), which opens the seven configuration panels.

Planning in this tab — nothing is running on :8080 and nothing needs to be. legend-lite's planner is compiled to WebAssembly and runs on a worker here, so the Pure below is compiled by the real planner and the SQL it returns is what DuckDB-WASM runs. Open index-server.html to route the same queries through a legend-lite server instead.
