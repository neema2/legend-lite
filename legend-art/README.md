# legend-art, lite

The look Query, Studio and (later) DataCube share, modelled on upstream's `@finos/legend-art`. Everything here
is **vendored data**: no app depends on an icon or font package, and this package has no dependencies either.

## Icons: `src/icons.ts`

Upstream Legend's icons, under upstream's names (`legend-art/src/icon/Icon.ts`), as SVG strings with the same
paths react-icons draws. Generated once, committed, and never regenerated by the build:

```
curl -sLo .scratch/react-icons.tgz https://registry.npmjs.org/react-icons/-/react-icons-5.5.0.tgz
openssl dgst -sha512 -binary .scratch/react-icons.tgz | base64   # MEFcXdkP...CW37Xiw== (the file header has it whole)
mkdir -p .scratch/react-icons && tar -xzf .scratch/react-icons.tgz -C .scratch/react-icons
node legend-art/tools/icons.mjs .scratch/react-icons/package > legend-art/src/icons.ts
```

5.5.0 is the version legend-studio pins. To add an icon: add its row to `ICONS` in `tools/icons.mjs` (our name,
the react-icons set and name, upstream's name), run the above, and read the diff.

## Fonts: `fonts/`

Upstream's type (`legend-art` `_fonts.scss`): Roboto (300, 400, 500, 700, 900; latin, and latin-ext at 400, 500
and 700 for DataCube), Roboto Mono (400, 700) and Raleway 900, as `.woff2`, copied from `@fontsource/*` 5.3.0.
SIL Open Font License 1.1: `fonts/LICENSE-*.txt`. Each site serves them from `./vendor/fonts/`
(`//legend-art:fonts`).
