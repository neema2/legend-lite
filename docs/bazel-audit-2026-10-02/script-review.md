**This sheet recommends; it decides nothing and deletes nothing.** The **Decision** column is for the user. Standing decisions: `experiments/` is kept and stays bazelignored; nothing is deleted before review; Python is first-class through rules_python, so "rewrite in Java" is never a goal here.

## How this was built

- **Candidates.** Every tracked `.py`, `.sh`, `.bash`, `.ps1`, `.mjs`, `.js`, `.ts`, `.cjs`, plus `.java` under `docs/`: 526 files. No `.bash`, `.ps1` or `.cjs` file is tracked.
- **Wired or not.** I used `bazel query "kind('source file', deps(<every package outside experiments/>))"`, so a file counts as wired if any target reaches it, including through `glob()`. A grep of BUILD files for names misses globs.
  - 339 are wired (listed briefly at the end).
  - **187 are not**, and each has a row below.
- **Runs today?** Judged by reading the code, not by running it.
- **Lines and dates.** `wc -l` and `git log -1 --format=%cs`.
- **Referenced by.** Comes from `git grep -l -E` for the basename as a whole word (so `check.py` does not match `arrow_check.py`), excluding the file itself. Basenames that occur more than once in the repo (`build.py`, `Probe.java`, `scoreboard.py`, `probe.ts`, `tile-layout*.ts`) were matched as `<dir>/<basename>`, or bare only within the same directory. Java probes that READMEs cite by class name have that README added by hand. At most 5 are shown.
- **Options.** 1 = wire as-is (`py_binary` / `js_binary` / `java_binary`, or a `py_test`); 2 = repair, then wire; 3 = keep as history (`docs/history/` or a bazelignored attic with a README); 4 = retire. **K** = keep in place in `experiments/` (user decision).
