**The verdicts.** CORRECTION: the new text is upstream's (recorded, no register row). DEFECT FIXED: the old text was
wrong. RULED: the user ruled it. TOWARD UPSTREAM: the new text diverged from upstream where the old did not or both
did; moved to upstream's with S1.5 (a move toward upstream needs no asking). WANTED: the two upstreams disagree, or the
nearest upstream is a different route, or the text is not the writer's (the lowering's print, pre-existing on every
output); the user picks, and until then lite's text stands (a register row where it is a divergence). FINDING: not a
spelling; an open finding (track F). NO DIFFERENCE: a random value in the same form.

   does; `ResultWritersTest.engineTokens` pins it. A nested one keeps the name as a string (the engine's JSON library's

- G5's SQL-side twin (a minute-precision text's zone, `dateTimeTextOfText`): recommend legend-pure's rule (a zone from
